# MAC 312 Project 9 · Neural-network capacity and generalization

A NumPy implementation of logistic regression and a one-hidden-layer neural network, evaluated on noisy XOR and the Wisconsin Diagnostic Breast Cancer dataset. The [report](report/report.tex) contains the derivation, protocol, results, and limitations. The [team review map](TEAM.md) points all six members to their completed workstream.

## Reproduce the results

Use Python 3.10 or newer. From the repository root, in an activated virtual environment:

```sh
python -m pip install -e .
python -m unittest discover -s tests -v
python -m topic9.experiments --output results
python -m topic9.figures results
```

For an end-to-end check that writes to a separate directory:

```sh
python -m topic9.experiments --quick --output smoke-results
python -m topic9.figures smoke-results
```

The full run covers 91 experiment conditions with 15 paired repetitions per condition. The same fit is reused where different comparisons call for identical settings. Figures and raw results in `results/` were generated from the full run. `runs.csv` contains selected-model scores, compute, and stop reasons. `curves.csv` contains the regularization training and validation trajectories. `tuning.csv` records every weight-decay candidate and its validation score. `protocol.json` records seeds, search settings, and numerical gradient checks. See [dataset provenance](data/README.md) for the real dataset citation and license.

## Runtime benchmark and convergence study

```sh
python -m topic9.benchmark --output results
python -m topic9.sensitivity --output results
python -m topic9.figures results
```

`benchmark` times the 16 compute-budget conditions on matched seeds and writes `runtime.csv` (one row per timed repeat), `runtime_summary.csv` and `runtime.json` (machine description and cost-model fits). `sensitivity` varies the update cap and the learning rate on noisy XOR and writes `convergence.csv` and `convergence.json`. Both accept `--quick` for a one-seed smoke test. The convergence results are deterministic. The timings depend on the machine, so reruns will differ from the archived values. The figures `runtime.svg` and `convergence.svg` are written next to the others. The [report](report/report.tex) discusses both.

## Report and notebook

The report is a LaTeX file, [report/report.tex](report/report.tex), and the compiled [report/report.pdf](report/report.pdf) is included. To rebuild it after regenerating the figures:

```sh
python -m topic9.figures results --output-dir report/figures --format pdf
cd report && latexmk -pdf report.tex
```

The standalone notebook [notebooks/topic9_project.ipynb](notebooks/topic9_project.ipynb) runs the project end to end and does not need this repository. It is generated by `notebooks/build_notebook.py`.
